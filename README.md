# 🐍 Snake Game

A simple and fun Snake Game developed using Java.

## 📖 About the Project

This project is a classic Snake Game where the player controls a snake, collects food, and grows in size while trying to avoid collisions.

The game demonstrates core Java programming concepts such as:
- Object-Oriented Programming (OOP)
- Event Handling
- Game Logic Development
- Collision Detection
- Score Tracking

## 🚀 Features

- Smooth snake movement
- Food generation system
- Score tracking
- Collision detection
- Game over screen
- Simple and interactive gameplay

## 🛠️ Technologies Used

- Java
- Java Swing / AWT (if used)
- Object-Oriented Programming

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/VivekCodes415/snake-game.git
```

2. Open the project in your preferred Java IDE.

3. Compile and run:

```bash
javac snakegame.java
java snakegame
```
